# Промпты, использованные при разработке приложения

1. Сгенерируй базовую структуру приложения Flutter для трекера расходов (основной экран, темная тема).
2. Напиши файл pubspec.yaml с необходимыми зависимосями: shared_preferences, intl.
3. Создай файл лицензии BSD-3-Clause и файл конфигурации анализатора (analysis_options.yaml) с правилом include: package:flutter_lints/flutter.yaml.
4. Помоги оформить репозиторий на GitHub в соответствии с требованиями олимпиады.
