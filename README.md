# Трекер Расходов (Flutter / ОС Аврора)

Мобильное приложение для ведения учета личных и служебных расходов. 

## Функционал приложения
- Ручное добавление, редактирование и удаление трат (сумма, категория, дата, комментарий, получатель, способ оплаты).
- Прикрепление фотографий чеков (с камеры или из галереи).
- Импорт трат из локальных CSV-файлов.
- Управление категориями (стандартные и собственные).
- Разделение расходов по командировкам.
- Визуализация данных: дашборд с графиками и фильтрация списка трат.

## Требования к окружению
- Целевая версия Flutter: `3.35.7+`
- Версия ОС Аврора: `5.1.6+ < 5.2`
- Хранение данных: локальное.

## Технологии
- Язык программирования: Dart
- Фреймворк: Flutter
